# YT Lyrics

YouTube の再生に合わせて、Apple Music 風の同期歌詞を表示する Chrome / Edge 拡張機能（個人利用）。

- 歌っている行を灰色→白に塗り、歌われた文字は少し浮かび上がる
- キー固定なしの速度変更（半音単位・スライダー）。YouTube 本来の速度メニューもキー固定なしになる
- slowed / sped up 版にも同期（タイトルから判別し、歌詞データと動画の長さの比で自動合わせ。手動調整も可）
- リピート、行クリックでシーク、Ctrl+クリックでタイミング補正（動画ごとに保存）
- 歌詞は [LRCLIB](https://lrclib.net) から取得

## 入れ方

1. `chrome://extensions`（Edge は `edge://extensions`）を開く
2. デベロッパーモードをオン
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方

| 操作 | |
|---|---|
| 開く / 閉じる | プレイヤー右下の歌詞ボタン、`Shift+L` / `Esc` |
| 再生オプション | 曲名横の `⋯` か、速度表示（`1.00x`）を押す |
| 歌詞を選び直す | 右上の 🔍 |
| 行へ移動 | 行をクリック |
| タイミング補正 | 今歌っている行を `Ctrl+クリック` |
| 歌詞を見回す | ホイール（3 秒で自動追従に戻る） |

## 構成

| ファイル | 役割 |
|---|---|
| `content.js` | 画面・同期・操作 |
| `core.js` | LRC 解析、行内の塗りの按分、タイトルからの曲名推定、候補の採点（DOM 非依存） |
| `style.js` | 見た目（Shadow DOM に適用） |
| `page.js` | ページ側でプレイヤー API から動画情報を取る |
| `background.js` | LRCLIB への問い合わせ |
